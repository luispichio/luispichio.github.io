## Description

RIM1370 es un nuevo dispositivo de la familia RIM de Tesacom / TwinDimension y evolución del RIM1360, una Unidad Terminal Remota (RTU) orientada a aplicaciones de Internet de las Cosas Industrial (IIoT).

El proyecto corresponde al firmware del dispositivo, desarrollado para un controlador RV1103 con Linux embebido. Su objetivo es adquirir variables de campo, gestionar conectividad LTE y preparar la integración con plataformas de monitoreo como T.DATA.

## Características

- Firmware para RTU industrial orientada a telemetría y monitoreo remoto.
- Servicios embebidos en C sobre Linux Buildroot.
- Integración con entradas digitales y analógicas para sensores de campo.
- Soporte para variables como temperatura, presencia, caudal, presión, nivel y señales operativas.
- Conectividad mediante módem LTE.
- Integración con protocolos IIoT e industriales como Modbus, IEC104, DNP3 y MQTT.
- Soporte para comunicación serial y transmisión transparente.
- Build, empaquetado y despliegue reproducibles para firmware de campo.

## Aplicaciones

- Telemetría de activos industriales.
- Monitoreo de acueductos.
- Monitoreo de tanques y calidad del agua.
- Gestión de centrales meteorológicas.
- Medición de variables ambientales y de proceso.
- Integración con dashboards y visualización remota en T.DATA.
